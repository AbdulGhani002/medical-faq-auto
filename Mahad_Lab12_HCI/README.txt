HOW TO USE WITH FIGMA
---------------------
1. Open Figma -> New design file.
2. Drag the SVG files from /svg straight onto the canvas - they import
   as fully editable vector layers (frames, text, shapes).
3. Recolour / tweak as you like, then wire up the prototype:
   Login -> Dashboard -> Search -> Appointment -> Payment -> Success,
   plus the wrong-password error path back to Login.
4. Share -> "Anyone with the link can view" -> copy the link into
   Mahad_FigmaLink.txt.
